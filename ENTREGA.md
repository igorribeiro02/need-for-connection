# Como entregar o protótipo no Classroom

1. **Link do jogo (principal):** https://igorribeiro02.github.io/need-for-connection/
2. **Arquivo para abrir sem internet:** https://igorribeiro02.github.io/need-for-connection/NeedForConnection.html
   (um único arquivo `.html`; baixe e abra com duplo clique no Chrome, Edge ou Firefox. Funciona no celular também.)
   Para gerar localmente: `npm run build:offline` → `dist-offline/index.html`.
3. **Código:** https://github.com/igorribeiro02/need-for-connection
